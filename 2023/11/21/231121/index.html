eclipse与springMVC排错两则

简单配置tomcat服务

导入war的时候直接把我服务配置整没了。

我直接（run on service菜单）manually define a new server。

然而提示端口（prot）出问题

没关系，直接上方菜单 窗口->显示视图->其他->搜索框搜索server，把下方server栏打开，双击服务（tomcat 9.0 serve）进行一个服务的配置

看到右边“Ports”只改两项：Tomcat admin port : 8082,HTTP/1.1:8081

ctrl+s保存一下

500 …… nested exception is java.lang.IllegalArgumentException: Unsupported class file major version 61

报错信息不但比我的显示器高，还比我的显示器宽……所以就不贴了

这个是第一条根本原因的最后一小句话

搜了一下，大致意思就是：spring还不适配java17。。。

哈人，eclipse自带了一堆jre，难怪左侧项目管理中的：
项目名/Java Resources/Libraries/JRE系统库[Javase-17]
与我的lab是如此的格格不入

直接右键->属性 点开执行环境的下拉菜单，选取熟悉的JavaSE-1.8(jre),应用并关闭
