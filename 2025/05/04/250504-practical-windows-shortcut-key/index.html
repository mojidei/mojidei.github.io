实用windows快捷键

2025-05-04
未分类
4.2k 词
  • windows
  • 快捷键

文本编辑

剪切、复制、粘贴

快捷键 功能
Ctrl + X 剪切所选文字。
Ctrl + C 复制所选文字。
Ctrl + Insert
Ctrl + V		 粘贴剪贴板中的最后一项。
Shift + Insert
Ctrl + Shift + V		 粘贴为纯文本。

查找与替换

快捷键 功能
Ctrl+F 查找文本。
Ctrl + H 查找和替换文本。

撤销与重做

快捷键 功能
Ctrl + Z 撤消上一次的键入操作。
Ctrl + Y 重新执行通过 Ctrl + Z 撤消的键入操作。

删除

快捷键 功能
Backspace 删除光标左侧的字符。
Del 或 Delete 删除光标右侧的字符。
Ctrl + Backspace 删除光标左侧的字词。
Ctrl + Del 删除光标右侧的字词。

格式

快捷键 功能
Ctrl+B 将粗体格式应用于所选文本。
Ctrl + I 将倾斜格式应用于所选文本。
Ctrl + U 将下划线格式应用于所选文本。

缩进

快捷键 功能
tab 将光标缩进一个制表位。

移动光标

快捷键 功能
向上键 将光标向后移动到上一行。
向下键 将光标向前移动到下一行。
向左键 将光标向后移动到上一个字符。
向右键 将光标向前移动到下一个字符。
主页（Home） 将光标向后移动到行的起始处。
End 将光标向前移动到行的末尾。
Ctrl + 向上键 将光标向后移动到上一个段落的起始处。
Ctrl + 向下键 将光标向前移动到下一段落的起始处。
Ctrl + 向左键 将光标向后移动到上一个字词的起始处。
Ctrl + 向右键 将光标向前移动到下一个字词的起始处。
Ctrl + Home 将光标向后移动到文档的起始处。
Ctrl + End 将光标向前移动到文档的结尾。
Page down 或 PgDn 将光标向前移动一个页面。
Page up 或 PgUp 将光标向后移动一个页面。

选择

快捷键 功能
Ctrl + A 选择所有文本。
Shift+向上键 从当前光标位置向后选择行。
Shift+向下键 从当前光标位置向前选择行。
Shift+向左键 从当前光标位置向后选择字符。
Shift+向右键 从当前光标位置向前选择字符。
Shift + Home 选择从当前光标位置到当前行起始处之间的文本。
Shift + End 选择从当前光标位置到当前行尾之间的文本。
Shift + Ctrl + 向上键 从当前光标位置向后选择段落。
Shift + Ctrl + 向下键 从当前光标位置向前选择段落。
Shift + Ctrl + 向左键 从当前光标位置向后选择字词。
Shift + Ctrl + 向右键 从当前光标位置向前选择字词。
Shift + Ctrl + Home 选择当前光标位置与文档起始处之间的文本。
Shift + Ctrl + End 选择当前光标位置与文档末尾之间的文本。
Shift+Page Down 从当前光标位置向前选择一页文本。
Shift+Page Up 从当前光标位置向后选择一页文本。

桌面和其他常规

快捷键 功能
Alt + 向左键 返回。
Alt + 向右键 前进。
Alt + Esc 按窗口打开顺序循环浏览。
Alt + Tab 在打开的窗口之间切换。 要在多个窗口间循环切换，可以持续按住 Alt 键并多次按 Tab 键。
Ctrl + Alt + Tab 查看所有打开的应用的缩略图。 使用箭头键在打开的应用之间切换。
Ctrl + F5
Ctrl + R		 刷新当前窗口。
F5 刷新活动窗口。
F6 循环浏览窗口中或桌面上的元素。

菜单

快捷键 功能
F10 激活活动窗口中的菜单栏。
Alt + A 将焦点设置到建议的操作菜单中的第一个图标。
Alt + 带下划线的字母 对于命令菜单或上下文菜单中的操作，某些窗口和应用会通过在操作名称中的某个字符下方添加下划线的方式来指定键盘快捷方式。按Alt键，然后按相应字母来执行该操作。

打开

快捷键 功能
Ctrl + Shift + Esc 打开任务管理器。
Alt+ 空格键 打开活动窗口的上下文菜单。
Ctrl + Alt + Del 切换到安全屏幕，在该屏幕上你可以锁定桌面、切换用户、退出登录、更改密码或打开任务管理器。

关闭

快捷键 功能
Esc 或 Escape 停止或退出当前任务，或者关闭对话框。
Alt+F4 关闭活动窗口。 如果没有打开任何窗口，则提示关闭。
Ctrl + F4 在可全屏显示且支持同时打开多个文档的应用中，关闭活动文档，但不关闭整个应用。

开始菜单

快捷键 功能
Windows 键 打开或关闭“开始”菜单。

截图

快捷键 功能
PrtScn 或 Print Screen 选择屏幕上的一个区域，以将屏幕截图捕获到剪贴板中。 然后你可以打开“截图工具”来共享或标记该图像。
Alt + PrtScn 捕获活动窗口的屏幕截图并将其复制到剪贴板。
Windows 键  + PrtScn 捕获全屏屏幕截图并将其保存到“图片”文件夹中的“屏幕截图”子文件夹里的一个文件中。
Windows 键  + Shift + S 选择屏幕上的一个区域，以将屏幕截图捕获到剪贴板中。 然后你可以打开“截图工具”来共享或标记该图像。

输入、输入法、键盘布局

快捷键 功能
Windows 键  + V 打开剪贴板历史记录。
Windows 键  + 句点 (.)
Windows 键  + 分号 (;)		 打开表情符号面板。
Ctrl + Shift 当有多个可用的键盘布局时，切换键盘布局。
Windows 键  + Ctrl + 空格键 切换到先前选定的输入选项。
Windows 键  + Shift + 空格键 按顺序向后切换输入语言和键盘布局。
Windows 键  + 空格键 按顺序向前切换输入语言和键盘布局。

Windows键

打开或打开与关闭

快捷键 功能
Windows 键  + I 打开设置。
Windows 键  + X 打开“快速链接”菜单。 此快捷方式的操作效果与右键单击“开始”菜单相同。
Windows 键  + Ctrl + V 打开快速设置的声音输出页面，该页面包含输出设备、空间音效以及音量混合器的设置。
Windows 键  + A 打开 Windows 11 操作中心。
Windows 键  + R 打开“运行”对话框。
Windows 键  + N 打开通知中心和日历。

分屏与窗口

快捷键 功能
Windows 键  + 向左键 将窗口贴靠到屏幕的左侧。
Windows 键  + 向右键 将窗口贴靠到屏幕的右侧。
Windows 键  + 向下键 最小化活动窗口。
Windows 键  + 向上键 最大化活动窗口。
Windows 键  + Shift + 向上键 将桌面窗口拉伸至屏幕顶部和底部。
Windows 键  + Shift + 向下键 如果窗口已贴靠或最大化，将其还原。
Windows 键  + Alt + 向上键 将活动窗口贴靠到屏幕的上半部分。
Windows 键  + Alt + 向下键 将活动窗口贴靠到屏幕下半部分。
Windows 键  + M 最小化所有窗口。
Windows 键  + Shift + M 还原最小化的窗口。
Windows 键  + Home 最小化或还原除活动窗口之外的所有窗口。

锁定

快捷键 功能
Windows 键  + L 锁定计算机。

桌面

快捷键 功能
Windows 键  + D 显示和隐藏桌面。

命令提示符

快捷键 功能
Ctrl + C
Ctrl + Insert		 复制所选文字。
Ctrl + V
Shift + Insert		 粘贴选定文本。
Alt + 选择键 开始在块模式下选择。
箭头键 按指定方向移动光标。
Ctrl + Home（历史记录导航） 如果命令行为空，则将视区移动到缓冲区顶部。 否则，请删除命令行中光标左侧的所有字符。
Ctrl + End（历史记录导航） 如果命令行为空，则将视区移动到命令行。 否则，请删除命令行中光标右侧的所有字符。

对话框

在对话框窗口（如系统警报或错误消息）中使用以下键盘快捷方式。

快捷键 功能
F4 显示活动列表中的项目。
Ctrl + Tab 在选项卡中向前移动。
Ctrl + Shift + Tab 在选项卡中向后移动。
Ctrl + 1、2、3… 移动到该选项卡编号。
tab 在选项中向前移动。
Shift + Tab 在选项中向后移动。
Alt + 带下划线的字母 执行可与该字母结合使用的命令（或选择该选项）。
空格键 如果活动选项为复选框，则选择或清除复选框。
Backspace 如果在“另存为”或“打开”对话框中选择文件夹，则打开上一级别的文件夹。
箭头键 如果活动选项是一组选项按钮，请选择一个按钮。

文件资源管理器

快捷键 功能
Windows 键  + E 打开文件资源管理器。
Alt + D 选择地址栏。
Ctrl + L 将焦点放在地址栏上。
F4 选择地址栏以更改当前路径。
Alt + Enter 显示所选项目的属性。
Alt + 向左键
Backspace		 导航到上一个文件夹。
Alt + 向右键 查看下一个文件夹。
Alt + 向上键 在文件夹路径中向上移动一级。
Alt + 使用鼠标拖动文件 当你放置文件时，在该位置创建指向原始文件的快捷方式。
Alt + P 显示或隐藏预览窗格。
Alt + Shift + P 显示或隐藏细节窗格。
Ctrl + D
Delete		 删除选定项，将其移至回收站。
Ctrl + E
Ctrl + F		 选择搜索框。
F3 搜索文件或文件夹。
Ctrl + 使用鼠标拖动文件 当你放置文件时，在该位置创建一个副本。
Ctrl + 鼠标滚轮 更改文件和文件夹图标的大小和外观。
Ctrl + N 打开新窗口。
Ctrl + 数字 (1-9) 移动到该选项卡编号。
Ctrl + 加号 (+) 调整所有列的大小以适应文本。
注意：此快捷方式需要使用数字键盘。
Ctrl + Shift + E 展开导航窗格中所有文件夹的树状结构。
Ctrl + Shift + N 新建文件夹。
Ctrl + Shift + Tab 移动到上一个选项卡。
Ctrl + T 打开新选项卡并切换到该选项卡。
Ctrl + W 关闭活动选项卡。 如果只有一个选项卡打开，则关闭窗口。
Ctrl + Tab 移动到下一个选项卡。
Home 滚动到活动窗口的顶部。
End 滚动到活动窗口的底部。
F2 重命名所选项目。
F5 刷新窗口。
F11 最大化或最小化活动窗口。
向左键 折叠当前选择内容（如果已展开），或选择该文件夹所在的文件夹。
向右键 显示当前选择内容（如果已折叠），或选择第一个子文件夹。
Shift+Delete 永久删除所选项，而不将其移至回收站。

多个桌面

快捷键 功能
Windows 键  + Tab 打开任务视图。
Windows 键  + Ctrl + 向右键 在你已创建的位于右侧的其他桌面之间进行切换。
Windows 键  + Ctrl + 向左键 在你已创建的位于左侧的其他桌面之间进行切换。
Windows 键  + Ctrl + D 创建另一个桌面。
Windows 键  + Ctrl + F4 关闭正在使用的桌面。

任务栏

以下列表包含用于操作 Windows 任务栏、已固定应用以及通知区域的键盘快捷方式。

快捷键 功能
Shift + 选择任务栏上的应用图标 打开应用的另一个实例。
Ctrl + Shift + 选择任务栏上的应用图标 以管理员身份打开应用。
Windows 键  + 数字 (0-9) 打开固定到任务栏的应用（位于数字所指明的位置）。 如果应用已处于运行状态，则切换至该应用。
Windows 键  + Shift + 数字 (0-9) 启动固定到任务栏的应用的新实例（位于数字所指明的位置）。
Shift + 右键单击任务栏上的应用图标 显示应用的窗口菜单。
